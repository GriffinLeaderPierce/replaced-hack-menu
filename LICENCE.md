## 🧩 About

**Replaced Companion** is a curated list of Replaced open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat readouts, scene switcher
- **Quality-of-Life Helpers** — combat catalog, upgrade notes, route planner
- **Research Notes** — encounter layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Scene Switcher — jump between checkpoints in a run
- Hitbox Notes — visualize melee and ranged hitboxes
- Run Review — record and review combat sequences
- Playback Speed — adjust review playback for study (0.1x to 5x)

### Wallhack
- Entry Catalog — browse upgrades, augments, and status effects
- Loadout Notes — organize combat and utility options
- HUD Tweaks — improved on-screen readability

### Aimbot
- Practice Notes — segment study on any encounter
- Stamina Readout — track resource flow mid-fight
- Input Notes — chain complex maneuvers in the training room
